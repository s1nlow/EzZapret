# EzZapret

Графический интерфейс для управления Windows-сборкой `zapret` от Flowseal.

EzZapret избавляет от необходимости каждый раз вручную запускать `service.bat`, выбирать стратегию и настраивать списки.

> EzZapret — независимый проект. Он не является официальной частью `zapret` или Flowseal.

## Возможности

- автоматическая установка последней версии `zapret` при первом запуске;
- запуск и полная остановка обхода без окна консоли;
- выбор стратегии обхода;
- проверка стратегий;
- диагностика;
- Game Filter;
- IPSet Filter;
- ручное обновление `zapret`;
- выбор конкретной версии `zapret`;
- просмотр изменений релиза;
- пользовательские списки, которые сохраняются при обновлении;
- экспорт и импорт настроек;
- сброс настроек `zapret`;
- сохранение настроек EzZapret между запусками.

## Скачать

Готовые сборки находятся в разделе [Releases](https://github.com/s1nlow/EzZapret/releases).

Скачайте архив последнего релиза и распакуйте его в отдельную папку.

## Первый запуск

Запустите `EzZapret.exe` от имени администратора.

Если папки `zapret` ещё нет, программа автоматически скачает последнюю доступную версию.

После первой установки новые версии автоматически не загружаются. EzZapret только сообщает о доступном обновлении, а загрузка выполняется вручную.

## Обновление zapret

В настройках доступны два варианта:

- **Обновить zapret** — установить последнюю доступную версию;
- **Выбрать версию** — выбрать конкретный релиз из списка.

Перед загрузкой выбранной версии пользователь возвращается в меню параметров, где отображается прогресс скачивания и распаковки.

Для каждой версии можно открыть **«Что нового?»** и посмотреть описание изменений из GitHub Release.

## Стратегии

EzZapret показывает доступные `.bat`-стратегии из установленного `zapret` и позволяет выбрать нужную без ручного запуска файлов.

Если текущая стратегия перестала работать, попробуйте другую. Работоспособность конкретной стратегии зависит от провайдера, DPI и текущей версии `zapret`.

## Проверка стратегий

**«Проверка стратегий»** запускает тестирование доступных стратегий.

Используйте этот раздел, чтобы найти стратегию, которая работает в вашей сети.

## Диагностика

**«Диагностика»** сразу запускает проверку распространённых причин, из-за которых `zapret` может не работать.

Проверяются основные файлы `zapret`, `winws.exe`, WinDivert, выбранная стратегия, состояние обхода и доступность GitHub по HTTPS.

Если диагностика показывает проблему, сначала устраните её, а затем повторите проверку.

## Game Filter

Game Filter используется для трафика игр и других приложений, использующих TCP/UDP.

В EzZapret доступны:

- `Disable`;
- `TCP`;
- `UDP`;
- `TCP and UDP`.

Набор возможностей зависит от установленной версии `zapret`.

## IPSet Filter

Доступны три режима:

- `None` — IPSet не используется;
- `Loaded` — используются адреса из загруженного списка;
- `Any` — фильтр применяется к любым IP-адресам.

При проблемах с отдельными сайтами или приложениями рекомендуется сначала проверить работу с `None`.

## Пользовательские списки

EzZapret использует пользовательские файлы, которые не должны заменяться содержимым нового релиза `zapret`.

- `list-general-user.txt` — дополнительные домены для обхода;
- `list-exclude-user.txt` — домены, которые не нужно обходить;
- `ipset-exclude-user.txt` — IP-адреса и подсети, которые не нужно обходить;
- `ipset-all-user.txt` — дополнительные IP-адреса и подсети для обхода.

Это позволяет сохранять собственные правила после обновления `zapret`.

## Экспорт и импорт

Внизу раздела пользовательских списков доступны:

- **Экспорт настроек** — создаёт резервную копию пользовательских данных;
- **Импорт настроек** — восстанавливает их.

## Сброс настроек

EzZapret позволяет вернуть настройки `zapret` к стандартным.

Перед сбросом программа запрашивает подтверждение, чтобы исключить случайное удаление пользовательских настроек.

## Запуск из исходников

Требуется Windows и Python 3.10 или новее.

```bat
git clone https://github.com/s1nlow/EzZapret.git
cd EzZapret
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Для управления системными компонентами `zapret` рекомендуется запускать приложение от имени администратора.

Также можно использовать:

```bat
run.bat
```

## Сборка

Для сборки `.exe` используйте:

```bat
build.bat
```

Скрипт автоматически создаёт виртуальное окружение, устанавливает зависимости и собирает приложение через PyInstaller.

Готовый файл находится в:

```text
dist\EzZapret.exe
```
